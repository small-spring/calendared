# Calendared の使い方（日本語）

Calendared は、日・週・月・四半期・年のノート（周期ノート）を作って行き来するための Obsidian のプラグインです。
カレンダー、ノートの上の帯（パンくずとミニカレンダー）、コマンドから開けて、ノートに絵文字を 1 つ「ステッカー」として付けられます。
詳しい説明は英語の [README](../../README.md) にあります。ここはその要約です。

Obsidian 1.13.1 以降で動きます。パソコンでもスマホでも使えます。

## 入れ方

まだコミュニティプラグインの一覧にはないので、このリポジトリから自分でビルドして入れます。パソコンで行います。

1. [Node.js](https://nodejs.org/) を入れる（LTS の版でよい）
2. リポジトリを手元に持ってくる。非公開なので GitHub へのサインインが要る（GitHub Desktop で「Clone」してもよい）

   ```bash
   git clone https://github.com/small-spring/calendared.git
   cd calendared
   npm install
   ```

3. ビルドして Vault に入れる（`/path/to/vault` は自分の Vault のフォルダ。中に `.obsidian` フォルダがあるところ）

   ```bash
   npm run deploy -- "/path/to/vault"
   ```

   テストとビルドをしてから、`main.js`・`manifest.json`・`styles.css` を Vault の `.obsidian/plugins/calendared/` にコピーします。
   Windows では、Git に付いてくる「Git Bash」で `bash scripts/deploy.sh "/c/path/to/vault"` と実行します
4. Obsidian の「設定 → コミュニティプラグイン」で **Calendared** をオンにする（初めてなら「制限モード」をオフにする）

絵文字を日本語で検索したいときは、続けて次を実行し、Obsidian を再起動します（設定の「Emoji search languages」から追加する方法は、
リポジトリが非公開の間はダウンロードに失敗します）。

```bash
npm run emoji-language -- ja "/path/to/vault"
```

**スマホで使うとき**: パソコンの Vault に入れたあと、同期でスマホに `.obsidian/plugins/calendared/` フォルダを届けます。
Obsidian Sync なら、同期の設定で「インストール済みのコミュニティプラグイン」をオンにします。

**新しい版にするとき**: リポジトリで `git pull` してから、手順 3 をもう一度実行し、Obsidian を再起動します（プラグインをオフ → オンでもよい）。

## はじめに

1. 「設定 → Calendared」の **Periodic notes** で、使う周期をオンにする（最初は日と週がオン）。周期の行を押すと、
   ノートの名前の書式・フォルダ・テンプレートを決められる
2. 左のリボンのカレンダーのアイコン（またはコマンド「Calendared: Toggle calendar interface」）でカレンダーを開く
3. 日付を押すと、その日のノートが開く（なければ作るか聞かれる）
4. 周期ノートを開いて、タブの右上の 😊+ のボタンを押すと、絵文字を 1 つ付けられる

## できること

- **カレンダー**: 日付・週番号・月・年を押すと、そのノートを開く（なければ作る）。ノートがあればドット、ステッカーがあれば絵文字が出る。
  右クリックで、新しいタブで開く・複製・ステッカー・削除など。Ctrl/Cmd を押しながらホバーすると中身をちらっと見られる
- **パンくずとミニカレンダー**: ノートの上の帯。パンくず（`2026 › Q4 › 10月 › W44 › 30日`）で上の周期のノートへ、
  ミニカレンダーで前後のノートへ移れる。設定で、消す・スマホだけにする・PC では右上の小さな箱にする、ができる
- **Open now**: タブの右上とカレンダーの右上のボタン。今日のノート（日を使っていなければ、今週や今月のノート）を開く
- **ステッカー**: 1 つのノートに絵文字を 1 つ。ノートのプロパティ（`sticker: 👍`）に入るので、プラグインを外しても残る。
  付けるのは、タブの右上のボタン、コマンド「Manage sticker」、カレンダーの右クリックのどれでも
- **週**: Google カレンダーと同じ考え方。週の始まり（土・日・月）を選べて、週番号は ISO 8601（年明けの週の数え方が決まっている）
- **年度**: 四半期と年を、それぞれ好きな月から始められる（下の「四半期と年を好きな月から始める」）
- **移行**: 書式やステッカーのプロパティの名前を変えたあと、前の名前のノートをまとめて変換できる（設定の一番下の「Migrate notes」）。
  先に一覧が出るので、確かめてから実行する

## 四半期と年を好きな月から始める

会社の年度などに合わせて、四半期と年の区切りを変えられます。「設定 → Calendared → Periodic notes」で
Quarterly notes（四半期）や Yearly notes（年）を押し、**Starts in** で始まりの月を選びます。四半期と年は別々に決めます。
同じ月を選べば揃います。

- 5 月を選ぶと、5〜7 月が Q1、2026 年 5 月〜2027 年 4 月が 1 つの年になります
- **Year in names**（1 月以外のときだけ出る）で、その年を始まりの年（2026）と終わりの年（2027）のどちらで呼ぶかを選びます。
  書式の `YYYY` と `Q` はこの数字になるので、たとえば書式を `YYYY[年度]` にすると「2026年度」になります
- パンくずやカレンダーでは、1 月以外から始まる年を「2026–27」と出します（ノートの名前は書式どおり）
- 始まりの月を変えても、今あるノートの名前は変わりません。`2026-Q4` は、新しい区切りの Q4 を指すようになります
- 日と月のノートは暦の年のままです（2027 年 3 月の月のノートは `2027-03`）

## おすすめのキーの割り当て

最初はキーが割り当てられていません。「設定 → ホットキー」で「Calendared」と検索して割り当てます。例:

| コマンド | キー |
| --- | --- |
| Open today's note（今日のノート） | Cmd+D |
| Open previous / next periodic note（前・次のノート） | Cmd+← / Cmd+→ |
| Open this month's note（今月のノート） | Cmd+M |
| Toggle calendar interface（カレンダーの表示） | Cmd+Shift+C |

Windows では Cmd の代わりに Ctrl です。Cmd+← / → は、ふだんは編集中に行の頭・終わりへ移るキーなので、割り当てるとそちらは使えなくなります。

## 書式の書き方

ノートの名前は、周期ごとの書式で決まります。使える記号は次のとおりです（設定画面でも、書式の欄の下に出ます）。

| 周期 | 必ず入れる | ほかに使える |
| --- | --- | --- |
| 日 | `YYYY` 年、`MM` 月、`DD` 日 | `YY` 年の下 2 桁、`M`・`D`（0 を付けない）、`MMM`・`MMMM`（月の名前）、`ddd`・`dddd`（曜日の名前） |
| 週 | `GGGG` 週の年、`WW` 週番号（ISO 8601） | `W`（0 を付けない） |
| 月 | `YYYY` 年、`MM` 月 | `YY`、`M`、`MMM`、`MMMM` |
| 四半期 | `YYYY` 年、`Q` 四半期（1〜4） | `YY` |
| 年 | `YYYY` 年 | `YY` |

- `[ ]` で囲んだ文字はそのまま入ります。たとえば `YYYY[年]MM[月]` は「2026年10月」
- 月や曜日の名前は、Obsidian の言語で書かれます
- 日のノートは、ISO の週の日付でも名前を付けられます。`GGGG-[W]WW-E`（週の年・週番号・曜日の 1〜7 を 3 つそろえて）
- 四半期と年の `YYYY`・`Q` は、始まりの月から数えた数字です（上の「四半期と年を好きな月から始める」）
- テンプレートの `{{date:...}}` だけは、どんな日付の書き方でもできます（年と四半期は暦のもの）

## 気をつけること

- 書式を変えると、前の書式の名前のノートはカレンダーに出なくなります（消えはしません）。書式の欄の下に警告が出るので、そこから今の書式に変換できます
- 書式に使える記号は周期ごとに決まっています（下の「書式の書き方」）。ほかの記号を入れるとエラーになります
- コアプラグインの「デイリーノート」もオンだと、同じ日のノートが 2 つできることがあります。日のノートはどちらか一方で作ってください
- テンプレートのファイルが見つからないとき（設定画面に「Template file not found」と出る）は、新しいノートは空で作られます。テンプレートのファイルは作りません
- 大きな移行の前には、バックアップ（Obsidian Sync の履歴など）があるか確かめてください
