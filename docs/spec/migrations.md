# 移行

すでにあるノートを、今の設定に合わせる操作。設定画面の一番下の「Migrate notes ›」（サブページ）にまとめている。
決めた理由は [ADR-0019](../adr/0019-one-format-per-period.md)・[ADR-0023](../adr/0023-migrations-without-content-changes.md)・
[ADR-0024](../adr/0024-migration-safety.md)・[ADR-0035](../adr/0035-migration-notice.md)。

## 1. 何があるか

**ファイルの中身を書き換えない移行だけを同梱する**。例外として、ステッカーのプロパティの付け替えは同梱する（プロパティを 1 つ移すだけで、
決めることが少なく、たまに要るため）。中身を書き換える移行は [todo.md](../todo.md) の「5. いつか」。

| 移行 | 使う場面 | ファイル |
| --- | --- | --- |
| 書式の変換 | 書式を変えたあと | 名前だけ変える |
| ステッカーのプロパティの付け替え | Sticker property を変えたあと | プロパティを書き換える |

## 2. 書式の変換

書式を変えると、前の書式の名前のノートは読めなくなり、カレンダーにも出なくなる（書式は周期ごとに 1 つ。ADR-0019）。それを今の書式の名前に変える。

- サブページの「Rename notes to the current format」に、オンの周期ごとに行がある。行には今の書式と「Previous format」の欄、ボタンがある
  - 前の書式は設定に残さないので、欄に入力する。移行の案内（4.）が出ている間は、変える前の書式が最初から入っている
  - 入力した書式は、書式の欄と同じ決まりで確かめる（その周期に要る文字がない、ほかの周期の書式と同じ、など）。誤りがあればボタンを押せない。
    日の行に月の書式を入れて、月のノートを日のノートとして読んでしまうのを防ぐ
  - 説明の 2 行目に、その書式で読めるノートの件数と、飛ばす件数を出す。ボタンは「Rename N notes…」（何が起きるかを書く）
- 対象は、周期のフォルダ（とその下のフォルダ）にある、前の書式がそのまま書く名前のノート。新しい名前は同じフォルダの中に付ける
- ボタンを押すと一覧（5.）が開く。実行すると、Obsidian のファイルの名前の変更（`app.fileManager.renameFile`）で 1 件ずつ名前を変える。
  ほかのノートからのリンクは、Obsidian の「内部リンクを自動で更新」がオンなら更新される
- **ぶつかるノートは飛ばす**（何も上書きしない）。次のときにぶつかったとみなす
  - 新しい名前のファイルがもうある（両方の書式で同じ日のノートを作っていたなど）。大文字・小文字だけの違いも同じとみなす（macOS などでは同じファイルになる）
  - 新しい名前が、ほかに変えるノートの今の名前と同じ（変える順で結果が変わらないように）
  - 一覧を見たあとに、新しい名前のファイルができた
- 1 つにするのは本人に任せる。名前を変えるだけなので、間違えても書式を戻してもう一度変換すれば戻せる

## 3. ステッカーのプロパティの付け替え

Sticker property の名前を変えると、前のプロパティにあるステッカーは見えなくなる（前のプロパティは読まない。
[ADR-0002](../adr/0002-read-only-configured-property.md)）。前のプロパティの値を、今のプロパティへ移す。

- サブページの「Move stickers to the current property」に「Previous property」の欄とボタンがある（ステッカーがオフのときは隠す）。
  移行の案内が出ている間は、変える前の名前が最初から入っている
- 対象は **周期ノートだけ**（どれかの周期の、今の書式とフォルダで読めるノート）。周期ノート以外で同じ名前のプロパティを別の用途に使っていても巻き込まない
- 実行すると、ノートごとに `processFrontMatter` で今のプロパティに値を入れ、前のプロパティを消す
  - 値はそのまま移す。空でも、絵文字でなくても移す（無理にでも移したい人のため）。絵文字でない値は、移してもステッカーとしては出ない
    （読み方は [stickers.md](stickers.md) の「4. 読み方」）
  - **今のプロパティがもうあるノートは飛ばす**（値が空でも）。一覧を見たあとに今のプロパティが付いたノートも飛ばす
  - `processFrontMatter` はプロパティ全体を書き直すので、ほかのプロパティの書き方（引用符や並び方）が整えられることがある。値は変わらない
- Obsidian 本体の「すべてのプロパティ」からも名前を変えられるが、そちらは周期ノート以外も対象になる

## 4. 移行の案内

書式や Sticker property を変えたあと、前の書式（プロパティ）のノートが残っていれば、変えた項目のすぐ下に警告を出す（ADR-0035）。

- 出る場所: 周期のサブページの書式の欄のすぐ下、Sticker property の説明の下。通知は出さない
- 文: 「N notes are still named in YYYYMMDD, so the calendar doesn't show them.」（プロパティは「… still have their sticker in "mood", …」）。
  ボタンは「Rename…」（「Move stickers…」）と「Keep as is」
  - 「Rename…」は、その周期の一覧（5.）をそのまま開く
  - 「Keep as is」は確認の画面を出す。ノートは変わらないこと、もう知らせないこと、あとで移行するなら移行のサブページで前の書式を入れることを書き、
    「Don't remind me」で前の書式（プロパティ）を忘れる
- 件数は、設定画面に出ている間、Vault から数え直す（名前を変えれば減る）
- 警告が出ている間は、周期の行と「Migrate notes」の行にも警告の印が付く
- **警告が消えるのは 2 つのときだけ**: 前の書式（プロパティ）のノートが 0 件になったとき（移行のあとと、設定画面を閉じるときに確かめて忘れる）と、
  「Keep as is」で「Don't remind me」を選んだとき
- 前の書式（プロパティ）は、警告が出ている間だけ覚える（`migrationNotices`。周期ごとに 1 つと、プロパティ 1 つ）
  - 警告が出ている間にもう一度変えたら、いちばん前の書式を覚えたままにする（ノートが使っているのはそちら）。入力の途中で保存されたときも同じ
  - 変えた先がいちばん前の書式と同じなら、警告ごと忘れる
  - 書式を変えた周期で前の書式のノートが 1 件もなければ、警告は出ない（設定画面を閉じるときに忘れる）

## 5. 一覧の画面

どちらの移行も、実行する前に必ず一覧を見せる（ADR-0024）。バックアップのボタンと「元に戻す」は作らない。

- 説明の文と、大きな変更の前にバックアップ（Obsidian Sync の履歴、Git、パソコンのバックアップ）を確かめるよう一言
- 各行: チェック、「前の名前 → 新しい名前」（ステッカーは「ノート : 値」）。最初は全部オンで、1 件ずつ外せる
  - ステッカーの値は、はじめの 16 文字だけ出す。値が絵文字でない行は、行の先頭に警告の色で「not an emoji」と出し、
    一覧の上にも何件が絵文字でないかを 1 行出す。チェックは外さない
- ぶつかるノートは、チェックなしで「Skipped: …」の下に並べる
- ボタン「Rename N notes」（「Move N stickers」）。チェックが 0 件なら押せない
- 実行中は、ボタンとチェックを押せず、画面も閉じられない。ボタンに「Renaming… 3/12」と進み具合を出す
- 終わったら、変えた件数と飛ばした件数を通知で知らせる
- もう一度押しても、済んだノートは対象にならないので何も変わらない
