# スクリーンショットの置き場所

ルートの [README.md](../../README.md) の先頭に載せる画像を置く。

撮るもの（ファイル名は README のコメントと合わせる。足すときは README にも足す）

- `calendar.png`: サイドのカレンダー。ドットとステッカーがいくつか付いた月
- `breadcrumbs.png`: 日のノートの上のパンくずとミニカレンダー

- 幅は 1000px くらいまでに縮める（GitHub の README の幅）。PNG で、個人的なノートの名前や中身が写らないようにする

撮り直すとき（2026-11-02 はこうした）

- 試しの Vault に、英語の見本ノート（2026 年 10 月の日のノートにステッカーをいくつか、週・月・四半期・年のノートも 1 つずつ）を
  `Daily/` などのフォルダに作り、設定のフォルダをそこに向ける。設定の Calendar language は English にする
- 日本語の文字が写らないように、Obsidian の「文書内のプロパティ」を隠し、ノートは読み取り表示にする。右のサイドバーにカレンダーを出す
- `obsidian dev:screenshot` で窓全体を撮り、`sips -c <高さ> <幅> --cropOffset <上> <左>` でカレンダーとノートの部分を切り出す
- 撮り終えたら、設定（`data.json`）とプロパティの表示を元に戻し、見本ノートをゴミ箱へ移す
