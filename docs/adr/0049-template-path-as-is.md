# ADR-0049 テンプレートの設定はファイルのパスそのもの（.md を補わない）。見つからなければ知らせて空で作る

- **背景**: 元の版は、設定画面ではテンプレートのパスに `.md` を補って確かめるが、ノートを作るときは補わずに読んでいた。
  そのため `.md` なしで保存された設定は、設定画面ではエラーが出ないのに、作ったノートにテンプレートが入らず空になった。何も知らせなかった
- **検討した案**
  - A. どこでも `.md` を補う（コアプラグインの「デイリーノート」「テンプレート」も `.md` なしを受け付ける）
  - B. 補わない。設定はファイルのパスそのもので、`.md` なしなら設定画面で「Template file not found」にする
- **決定**: B。あわせて、テンプレートを設定しているのにファイルが見つからないときは、ノートを作るときに
  「Daily note template not found: …」と知らせ、ノートは空で作る。テンプレートを設定していなければ、知らせずに空で作る（既定）
- **理由**
  - 設定に書いてあることと、実際に読まれるファイルが必ず一致する。どこかで勝手に補う所があると、食い違いが起きたときに気づきにくい
  - 欄の候補から選ぶと `.md` 付きのパスが入るので、手間はほぼ増えない
  - 空のノートを作って知らせるのは、テンプレートの設定の誤りで日記が書けなくなるのを避けつつ、誤りに気づけるようにするため
- **結果**: 前の版で `.md` なしで保存された設定は、設定画面でエラーが出るので、候補から選び直す。
  手で打つと `.md` まで打つ間はエラーが出る（保存はされない）
- **追記（2026-11-01）設定がファイルに付いていく**: 設定画面では、見つからないファイルは保存しない（「Template file not found (not saved)」。
  保存されている前の値が残る）。保存したあとにテンプレートのファイルやその上のフォルダを Obsidian の中で名前変更・移動したら、
  設定のパスも黙って新しいパスにする（Obsidian のリンクと同じ）。ファイルを消したときや、Obsidian の外で動かしたときは書き換えず、
  設定画面の「Template file not found」とノートを作るときの知らせで伝える。黙って空にすると、テンプレートが外れたことに気づけないため
