# ADR-0042 書式の記号の説明は自前で持ち、moment の文書を案内しない

- **背景**: 設定画面の書式の欄は「Must include」のあとに Moment.js の文書へのリンクを出し、README も「Moment.js tokens で書く」と
  案内していた。けれど周期ごとに使える記号を絞り（[ADR-0040](0040-format-tokens-per-period.md)）、四半期・年の `YYYY`・`Q` は
  始まりの月から数えた数字にした（[ADR-0039](0039-fiscal-year-in-period-pages.md)・[ADR-0041](0041-own-format-tokenizer.md)）。
  moment の文書には使えない記号が多く載り、`Q` は暦の四半期と書いてあるので、読むとかえって迷う
- **検討した案**
  - moment へのリンクを残し、違うところだけ書き足す
  - 自前の説明を、設定画面・README・使い方の 3 か所に持つ
- **決定**: 自前の説明を持つ
  - 設定画面の書式の欄の下に、その周期で必ず入れる記号と、ほかによく使う記号を意味つきで出す。一覧は `src/format-tokens.ts` の
    `formatTokenGuide` に置き、どれもその周期で使える記号であることをテストで確かめる（使える記号の決まりとずれない）
  - README と `docs/guides/usage-ja.md` に、周期ごとの記号の表を書く。四半期・年の `YYYY`・`Q` の意味もそこで説明する
  - 書き方が moment と同じこと（コアのデイリーノート・Periodic Notes・Templater の書式がそのまま使える）は、一言だけ書く
  - テンプレートの `{{date:...}}` はノートの中身で、どんな日付の書き方もできるので、ここだけは moment の文書を案内する
- **理由**
  - 設定画面の中だけで足りる。リポジトリが非公開の間も、外の文書を見なくてよい
  - 一覧をコードの決まりから確かめるので、使える記号を変えたときに説明が古くならない
- **結果**: 月や曜日の名前の記号は、よく使うものだけを載せる。`Do`（1st）などは載せていないが、使える
