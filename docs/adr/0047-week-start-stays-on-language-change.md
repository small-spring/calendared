# ADR-0047 カレンダーの言語を変えても、週の始まりは戻さない

- **背景**: 設定「Calendar language」を変えると、元の版のまま、週の始まりもその言語のふつうの週の始まりに戻していた
  （`switchLocale`）。週の始まりは週のノートが指す 7 日を決める（[ADR-0011](0011-week-follows-calendar.md)）ので、
  月や曜日の名前を変えたいだけの人の週のノートが、知らないうちに別の 7 日を指すようになる
- **検討した案**
  - A. 今のまま、言語に合わせて週の始まりも戻す
  - B. 言語だけを変え、週の始まりはそのまま
- **決定**: B
- **理由**
  - 言語は見た目、週の始まりはノートの意味。見た目を変える操作で意味が変わるのは驚く
  - 週の始まりは設定の一番上で、すぐ上の行にあるので、変えたい人は自分で選べる
  - 初めて入れたときの週の始まりは、今もカレンダーの言語の既定（[ADR-0046](0046-calendar-language-from-obsidian.md)）から取る
- **結果**: `switchLocale` は言語の設定だけを書く。設定画面は、週の始まりの選択肢の名前（新しい言語で書く）のために描き直す
