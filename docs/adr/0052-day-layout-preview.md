# ADR-0052 「Days shown」の下に、今日ならどう並ぶかを出す（並べる日は本物と同じ処理、描き方は簡単に）

- **背景**: ミニカレンダーの設定「Days shown」（Calendar week / 3 days each side）は、名前と説明だけでは違いがわかりにくい
- **検討した案**
  - A. 欄の下に、今日の日のノートでならぶ 7 日（曜日と日付、今日に印）を出し、値を変えるとすぐ変える
  - B. 説明文を値ごとに書きかえる（「今日なら 11 月 1 日〜7 日」など）
  - C. ノートの上に出る本物のミニカレンダーの部品をそのまま設定画面に出す
  - D. ミニカレンダーの日の並びだけを部品に切り出し、本物とプレビューで共用する
- **決定**: A。並べる日は本物と同じ `stripDates` で決め（`dayLayoutPreview`）、描き方は設定画面で簡単に書く
- **理由**
  - この設定で変わるのは「どの 7 日が並ぶか」だけで、見た目は変わらない。伝えたいことは並びで足りる
  - 本物とずれて困るのは並びのほうで、そこは同じ処理を使うのでずれない。ずれうるのは色や大きさだけ
  - 本物の日付のマス（`DateBttn`）はノートとつながっていて、押すとノートが開き、点やステッカーも出る。設定画面ではまぎらわしい（C）。
    D はミニカレンダー本体に手が入り、押したときの動きを止める工夫も要るわりに、得るものが見た目の一致だけ
  - B より A のほうが、週の始まりからか真ん中に今日かが、ひと目でわかる
- **結果**: `src/settings/ui/DayLayoutPreview.svelte` を説明の下に出す。週の始まりとカレンダーの言語に従う。README と日本語の使い方に書いた
