# ADR-0030 「Open now」ボタンを見出しバーとカレンダーに置き、一番細かい周期の今のノートを開く（カレンダーの ⌖ を置き換える）

- **背景**: 過去のノート（例: 10月の月次ノート）から今日に戻るには、カレンダーを開くか、コマンドを探す必要があった。スマホでは特に手間。
  また、⌖ はカレンダーでは「表示を今月に戻す」、タイムラインでは「表示をノートの日付に戻す」で、同じアイコンで意味が違っていた
- **検討した案**
  - A. カレンダーの ⌖（表示を今月に戻すだけ）を残し、見出しバーに Open now を足す
  - B. ⌖ をなくし、Open now は見出しバーだけ
  - C. カレンダーの ⌖ を Open now に置き換え、見出しバーにも同じ Open now を置く
- **決定**: C
  - 操作を「見る」（表示だけ動かす。ノートは開かず、作らない）と「開く」（ノートへ移る）に分けて考える。Open now は「開く」
  - 押したら: 有効にしている周期のうち一番細かいものの、今のノートを開く（日を使っていれば今日、日がオフなら今週、…）。
    なければ作る（ノートを作る前の確認の設定に従う）。あわせて、カレンダーの表示を今日の月にする（年や年の範囲のビューなら今年）
  - 薄くするとき: カレンダーでは、今のノートを開いていて、表示も今日の月のとき。見出しバーでは、今のノートを開いているとき
  - アイコンは `calendar-clock`（「今日」ではなく「今」）。名前は「Open now」
  - 見出しバーのボタンは、ステッカーのボタンと同じ仕組み（`view.addAction`）で、タイムラインとは別に置く
  - コマンドには足さない（下の「見送ったこと」）
- **理由**
  - カレンダーを動かしたあとに戻したいときの多くは、今に行きたいとき。今のノートを開けば、カレンダーも付いてくる（[ADR-0018](0018-when-displayed-month-changes.md)）
  - B はスマホで困る。カレンダーは画面を覆う引き出しなので、見出しバーのボタンを押すには一度閉じる必要がある
  - A は、見る ⌖ と開く Open now の 2 種類が並ぶ。C なら「今へ移る」はどこでも同じ意味になる
  - 表示を今日の月に直接移すのは、付いてくるのを待つと、週・四半期・年だけを使う人で表示が期間の最初の月（先月や 1 月）になるため
    （週が 9月 29日から始まると、今日が 10月でも 9月が出る）。ユーザーの移動の操作なので、ADR-0018 の (1) に収まる
  - カレンダーでは「両方済んでいるときだけ薄くする」。今のノートを開いたままカレンダーで過去を眺めている人が、戻せなくならないように
- **見送ったこと**: Open now のコマンド。日を使う人には「Open today's note」と同じで、違いが出るのは日を使わない人だけのため。
  見直すきっかけ: 日を使わない人から、ホットキーで今に行きたいという声が出たら
- **結果**: 今日のノートがまだなければ、カレンダーで今月を見たいだけでも作られる（確認の設定に従う）。
  見出しバーの Open now はすべてのノートに出し、設定「Open now button」（既定オン）で消せるようにする（2026-10-31 に決めた）。
  アイコンが Obsidian の同梱の Lucide にあるか（`getIconIds()`）と、見出しバーでの見え方は、作るときに確かめる
