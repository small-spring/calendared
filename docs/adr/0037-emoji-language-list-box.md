# ADR-0037 絵文字を検索する言語の一覧は、宣言の一覧（list）にせず、ステッカーの段の中の自前の箱のままにする

- **背景**: 宣言で書く設定（[ADR-0020](0020-settings-page-layout.md)）には、項目を足したり消したりする一覧（`type: 'list'`）がある。
  自前の箱（`EmojiLanguages.svelte`）と、Obsidian で並べて見比べた
- **検討した案**
  - A. 自前の箱を、ステッカーの段の「Emoji search languages」の行の、名前と説明の下に出す
  - B. 宣言の一覧。見出し付きの別の段になる。PC は見出しの右の「+」、スマホは「+ Add languages…」の行、消すのは「×」
- **決定**: A
- **理由**
  - B は独立した段になり、見出しが「Stickers」と同じ大きさで並ぶので、ステッカーとは別の機能に見える
  - B は見出しに説明を付けられず、どこからダウンロードするか（cdn.jsdelivr.net）を書けない
  - B は PC での追加の入口が見出しの小さな「+」だけで見落としやすい。「×」は一覧から外すだけにも読める
  - B のよさ（Obsidian の更新に見た目がついていく、言語の名前が設定の検索に出る）は、使う人にとっては小さい
- **結果**: 自前の CSS（`src/app.css` の `calendared-language-*`）を持ち続け、Obsidian の見た目が変わったら手で合わせる
