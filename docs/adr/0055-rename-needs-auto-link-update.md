# ADR-0055 書式の変換は、Obsidian の「内部リンクを毎回更新する」がオンのときだけ実行できる

- **背景**: 書式の変換（[ADR-0023](0023-migrations-without-content-changes.md)）は、Obsidian の名前の変更（`app.fileManager.renameFile`）で
  1 件ずつ名前を変える。Obsidian の設定「内部リンクを毎回更新する」（`alwaysUpdateLinks`、既定はオフ）がオフだと、1 件ごとに
  「リンクを更新」のダイアログ（常に更新 / 1 回だけ更新 / 更新しない）が出て、移行がそこで止まる。100 件なら 100 回たずねられる。
  一覧の説明も「オンならリンクが更新される」と書いていて、オフのときの動き（毎回たずねる）と合っていなかった
- **検討した案**
  - A. 一覧に「リンクも更新する」チェックを置く。オンなら移行の間だけ Obsidian の設定をオンにして Obsidian に書き換えさせ、終わったら戻す。
    オフなら `app.vault.rename` で名前だけ変える。手間は小さいが、利用者の設定を勝手に書き換える。途中で Obsidian が落ちるとオンのまま残る
  - B. オフのときは実行させず、先にオンにするよう伝え、設定の画面を開くボタンを置く
  - C. `app.vault.rename` で名前だけ変え、`metadataCache` のリンクの情報をもとに、各ノートのリンクを自分で書き換える。公開の API だけで済むが、
    リンクの形（相対パス、埋め込み、プロパティの中のリンクなど）を取りこぼすとリンクが切れる
- **決定**: B
- **理由**
  - 利用者の Obsidian の設定を勝手に変えない。オンにするかどうかは本人が決め、一度オンにすれば済む
  - リンクの書き換えは Obsidian 本体に任せる。自分で書き換えるより確か
  - リンクを更新しないで名前だけ変えたい人は、いまのところいない（必要になったら A のチェックを足す）
- **結果**
  - 設定がオフの人は、変換の前に Settings › Files and links でオンにする手間がある
  - 設定を読むのに非公開の `app.vault.getConfig` を使う。なくなったときは止めない（毎回たずねられる元の動きに戻る）
