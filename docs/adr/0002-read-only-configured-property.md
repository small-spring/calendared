# ADR-0002 読むのも設定のプロパティだけ（互換の読み取りをしない）

- **背景**: 一時期、設定のプロパティ → `tags` → 本文の順に探して、古い形式のステッカーも表示していた
- **決定**: 設定のプロパティだけを読む
- **理由**: ステッカーがどこにあるかが常に 1 か所に決まり、仕様も実装も単純になる。古い形式の扱いは移行の問題として切り離す（[ADR-0003](0003-migration-separate-from-stickers.md)）
- **結果**: 元の版で付けたステッカーや、設定でプロパティ名を変える前のステッカーは表示されない（ノートからは消えない）
