# ADR-0033 パンくずとミニカレンダーは見出しのトグルでオン・オフし、出す場所は「いつも / スマホだけ」の 2 択にする

- **背景**: [ADR-0031](0031-breadcrumbs-and-mini-calendar.md) では、それぞれに「出す場所: いつも / スマホだけ / 出さない」の 3 択を持たせた。
  作って設定画面で見ると、同じ画面の「Stickers」は見出しのトグルでオン・オフしていて、形がそろっていなかった
- **検討した案**
  - 今のまま 3 択（Always / Phone only / Never）
  - 見出しにトグルを付けてオン・オフし、オンのときだけ「Show on: Always / Phone only」の 2 択を出す（Periodic Notes の周期ごとのトグルに近い）
- **決定**
  - 「Breadcrumbs」「Mini calendar」の見出しにトグルを付ける（`enabled`。既定はオン）。オフのときは、その下の項目を隠す
  - 出す場所（`placement`）は `always` / `phone` の 2 択にする。オフにしても出す場所は残る
  - 「Compact on desktop」は両方に効くので、ミニカレンダーがオフでも、パンくずを PC に出していれば残す
  - 保存された `never` は、オフ（出す場所は `always`）に読み替える
- **理由**
  - 同じ画面のステッカーとそろう
  - 一番よく使うオン・オフがトグル 1 回で済む
  - 3 択だと、「スマホだけ」の人がいったん出さないにして戻すとき、前の値を選び直すことになる。トグルなら出す場所を覚えておける
- **結果**: 設定のキーが 1 つずつ増える（`breadcrumbs.enabled`・`miniCalendar.enabled`）。設定画面を Obsidian 1.13 の宣言で書く形に
  組み直すとき（[ADR-0020](0020-settings-page-layout.md)）、見出しのトグルが作れるかをステッカーと一緒に確かめる
