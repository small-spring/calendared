# ADR-0008 月・年などのタイトルにもステッカーを出す（タイムラインの下の帯には出さない）

- **背景**: ステッカーは日付のボタンにしか出ていなかった。月次・四半期・週次ノートなどのステッカーは、カレンダーのヘッダーの「10月」「2026」や、
  タイムラインの見出し（Q4、W43）では見えなかった
- **決定**
  - カレンダーのヘッダーの月・年のタイトルと、タイムラインの見出し（Q4、W43、年、月）には出す
  - タイムラインの下の帯（⌃・年月・‹ ›・⌖）の年月には出さない
- **理由**
  - 行ごとの役割で分ける。タイトルや見出しは、日付と同じく「周期ノートそのもの」を表す場所で、ドットでノートの有無も見せている。
    ステッカーも同じように見せると、ノートの状態の見せ方が揃う
  - 下の帯は「今どこを見ているか」と「移動」のための場所で、年月は灰色の小さな文字で控えめに置いている。絵文字を足すと帯の中で一番目立ち、
    案内の役割が薄れる。幅にも余裕がない（4 桁の年を入れるだけで調整が要った）
- **見せ方**: 日付と同じ `Sticker` 部品で、文字の右上に少し重ねて置く。タイトルの文字が大きくても、絵文字は日付のボタンと同じ小ささにする
  （`PeriodTitle` の `showSticker`）。ステッカー機能がオフなら出ない。タイムラインでは設定の「ステッカーを表示」（`timeline.displayStickers`）にも従う
