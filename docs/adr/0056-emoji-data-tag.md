# ADR-0056 絵文字の検索の言葉は、動かさないタグを指定して取る

- **背景**: 絵文字の検索の言語を足すと、プラグインはこのリポジトリの `data/emoji-keywords/<言語>.json` を jsDelivr か GitHub の raw から取る
  （[stickers.md](../features/stickers.md) の 10 章）。どの版から取るかは `EMOJI_DATA_REF` で決めていて、これまではコミットの ID だった。
  2026-11-04 に、メールアドレスを隠すために履歴を書き換えたら、コミットの ID が変わり、`EMOJI_DATA_REF` の指す先が push した履歴から消えた。
  そのまま公開していたら、どの言語も取れなかった
- **検討した案**
  - A. コミットの ID のまま（書き換えたら直す）
  - B. ブランチ（`custom`）
  - C. 動かさないと決めたタグ（`emoji-data-1`、作り直すたびに番号を上げる）
- **決定**: C
- **理由**
  - 出した版のプラグインが取る中身は、あとから変わってはいけない。保存したデータは取った版の名前と一緒に持ち、
    言語ごとの大きさ（`EMOJI_DATA_SIZES_KB`）も設定に出しているので、中身が変わるとずれる。B は中身が変わるうえ、jsDelivr がしばらく古い中身を返す
  - タグは filter-repo で履歴を書き換えても付け直されるので、A のように指す先が消えにくい。名前も読める
- **結果**
  - 一度 push したタグは動かさない・消さない。作り直したら新しい番号のタグを付け、タグも push する（[guides/development.md](../guides/development.md) の「絵文字の検索の言葉」）
  - タグの名前が変わったので、コミットの ID で保存していた人は 1 回だけ取り直しになる
