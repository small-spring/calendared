# ADR-0054 設定の一番上はノートを開く・作る設定から並べ、カレンダーの言語は一番下の見出し「Language」に移す

- **背景**: 設定の一番上の見出しのない段は、週の始まり・起動時に開く・カレンダーの言語・作成の確認・Open now のボタンの順で、
  似たものがまとまっていなかった。カレンダーの言語はほとんど変えないのに、一番目に付きやすい場所にあった
- **検討した案**
  - A. 開く・作る設定（起動時に開く、Open now のボタン、作成の確認）→ 週の始まり。言語は一番下（Migrate notes の上）の見出しのない段に移す
  - B. 週の始まりを先頭のまま、開く・作る設定をまとめ、言語は一番上の段の最後に置く
  - C. 開く・作る設定 → 週の始まり → 言語（カレンダーの見た目を後ろにまとめる）
- **決定**: A
- **理由**
  - よく触る設定ほど上に置く。開く・作る設定は使い始めに決めて、あとで変えることもある
  - 言語は既定（Obsidian の言語）のままで済むことが多く、一度決めたら変えない
  - 週の始まりは週のノートの日にも関わるので、一番上の段に残す
- **結果**: 言語を探すときは一番下までスクロールする（Obsidian の設定の検索では今までどおり見つかる）
- **追記（2026-11-02）**: 見出しのない段は、すぐ上の見出しの続きに見えた（言語は Stickers の、Compact on desktop は Mini calendar の
  項目だと思った）。そこで、言語には見出し「Language」を、Compact on desktop には見出し「Desktop layout」を付けた。
  まとめて 1 つの見出し（Display）にする案もあったが、Compact on desktop はパンくずとミニカレンダーのすぐ下に置いておきたいので分けた。
  これで設定画面に見出しのない段は、一番上の段だけになる
- **追記（2026-11-02）**: Migrate notes も、見出しのないまま Language の下にあると、言語の項目に見えた。ノートの名前をまとめて変える
  入口なので、見出し「Danger zone」を付け、見出しの字を Obsidian の警告の赤（`--text-error`）にした
