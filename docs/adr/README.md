## 書き方

ファイル名は `番号-英語の短い名前.md`。先頭にプロパティを付ける。

```markdown
---
id: 0028
title: "決めたことを 1 文で"
status: 採用
date: 2026-10-31
area: 設定
implemented: false
aliases:
  - ADR-0028
---
# ADR-0028 決めたことを 1 文で

- **背景**: 何に困っていたか
- **検討した案**: A. … / B. …
- **決定**: どれにしたか
- **理由**: なぜそれにしたか（退けた案の弱いところも）
- **結果**: 決めたことで起きること、まだ決めていないこと
```

- `status`: 採用 / 提案中 / 却下 / 置き換え。置き換えたときは、古いほうに `superseded_by: 0030`、新しいほうに `supersedes: 0012` を足す
- `area`: ステッカー / 周期ノート / 状態管理 / 設定 など
- `implemented`: 決めたことを作り終えたら `true`
- `aliases`: Obsidian で開いたときに `ADR-0028` で探せるようにする。以前の番号（`stickers ADR-006` など）もここに残している
- 決めたあとで考えが変わったら、本文を書き換えずに「**追記（日付）**」を足すか、新しい ADR で置き換える
- 状態の細かい事情（一部だけ提案中、など）は「**状態の補足**」に書く

docs フォルダを Obsidian の Vault として開くと、プロパティで絞り込んだり、Dataview で一覧にしたりできる。
