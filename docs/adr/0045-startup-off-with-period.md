# ADR-0045 起動時に開く周期をオフにしたら、起動時に開く設定も「Nothing」にする

- **背景**: 起動時に開くノートは、周期ごとの `openAtStartup` で持ち、設定画面では「Open on startup」の 1 つの選択肢として見せている
  （オンの周期だけが選べる）。起動時に開く周期をオフにすると、選択肢は「Nothing」に見えるが、`openAtStartup` は残っていた。
  そのため、あとでその周期をオンに戻すと、何も選んでいないのに起動時にそのノートがまた開くようになった
- **検討した案**
  - A. 今のまま覚えておき、オンに戻したら起動時に開くのも戻す
  - B. オフにしたときに、起動時に開く設定も「Nothing」にする。オンに戻しても起動時には開かない
- **決定**: B
- **理由**
  - 設定画面に「Nothing」と出ている間に、見えない値で起動時の動きが決まるのはわかりにくい。周期をオンにしただけで起動時の動きが変わるのは驚く
  - 戻したい人は、「Open on startup」でもう一度選べば済む（1 回の操作）
- **結果**: `setPeriodEnabled` が、オフにする周期の `openAtStartup` を消す。最後の 1 つでオフにできないときは何も変えない。
  前の版で保存した設定（オフの周期に `openAtStartup` が残っているもの）も、読み込むときに消す
