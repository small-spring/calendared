# ADR-0013 親子（年 ⊃ 期 ⊃ 月 ⊃ 日）は今は持たない

- **背景**: 「この月のデイリーノートを集める」のような、親子をたどる機能を作るなら、親子の関係が要る
- **決定**: 今は作らない。必要になったら、正体（[ADR-0009](0009-period-identity-by-name.md)）から親・子を求める関数として足す（データとして木を持たない）
- **理由**: 月のデイリーノートの一覧は、今は dataviewjs で作っていて困っていない。週は木に収まらないので、木を持つと週だけ例外になる
