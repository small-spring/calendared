# ADR-0038 周期のオン・オフは連動させない（週だけ・四半期だけでも使える）

- **背景**: 元の版には、周期のオン・オフの連動があった。日をオフにすると週もオフになり、週をオンにすると日もオンになる。
  月と四半期も同じで、日・月・年を全部オフにしようとすると、日が黙ってオンに戻る。理由は画面のどこにも出なかった。
  調べると、カレンダーの作りの都合だった。カレンダーの表示は日・月・年の 3 つだけで、週は日の表の左の列、四半期は月の表の左の列にしかない。
  元の版はオフの周期のノートも作れたので、「オフの周期の表は出さない」ことでつじつまを合わせていたと見える
- **検討した案**
  - A. 連動を残し、週と四半期のトグルに「Needs daily notes」などと理由を書く
  - B. 連動をなくす。週だけオンでも、ふつうの日の表を出す（日のマスは押してもノートを作らない。四半期と月も同じ）
- **決定**: B。最後の 1 つの周期はオフにできず、押したら通知で知らせる（カレンダーに出すものがなくなるため）
- **理由**
  - 週のノートだけを書く人は珍しくない。連動があると、使わない日のノートもオンにしなければならない
  - Calendared ではオフの周期のノートは作らない（すでにあるノートは開ける）ので、表を出しても余計なノートはできない
  - 連動は画面から理由が見えず、トグルが勝手に動くように見えた
- **結果**: 週だけ・四半期だけのときも、カレンダーはふつうの日（月）の表を出す。日のマスの見た目は変えない（ユーザーが、週だけでもふつうのカレンダーを見たいと言った。2026-10-31）。
  ノートのない日のマスを押すと、日のノートはオフだと通知が出る
  コマンド、パンくず、ミニカレンダー、Open now は、もともとどの組み合わせでも動く
