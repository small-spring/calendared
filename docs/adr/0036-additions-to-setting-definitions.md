# ADR-0036 宣言で書く設定で出せないトグル（周期の行、見出し）は、描かれた行に足す

- **背景**: 設定画面を Obsidian 1.13 の宣言で書く設定（`getSettingDefinitions()`）で組み直した（[ADR-0020](0020-settings-page-layout.md)）。
  宣言では、サブページへの行（`type: 'page'`）の右には要約と「›」しか置けず、見出し（`heading`）は文字だけで、右にはアイコンのボタン（`extraButtons`）しか置けない。
  決めていた形（周期の行の右にオン・オフ、[ADR-0033](0033-heading-toggles.md) の見出しのトグルと説明）がそのままでは作れない
- **検討した案**
  - 周期の行
    - A. トグルはサブページの一番上だけに置く（公開の API だけで済む）
    - B. 行を `render` で自分で描き、公開されていない `openPage` でサブページを開く（Obsidian の更新で壊れうる。サブページを自分で描くと設定の検索に出ない）
    - C. サブページは宣言のまま使い、描かれた行にトグルを足す
  - 見出し
    - 段の最初の行をふつうのトグルにする（ADR-0033 の形から変わる）
    - 見出しの右のボタンの置き場所（`extraButtons`）を借りて、トグルと説明を足す
- **決定**
  - 周期の行は C。行は宣言の `visible`（描くたびに呼ばれる）で描き終わりを知り、名前で行を探して「›」の前にトグルを足し、2 行目の要約も書き直す。
    サブページの一番上にもトグルを置く（A も兼ねる）
  - 見出しは `extraButtons` のコールバックでボタンを消し、その場所にトグルを、見出しの下に説明を足す（`src/settings/ui/rows.ts`）。
    トグルの付いた見出しは項目のない段にし、項目は次の段に分ける（段の項目がすべて隠れると、見出しごと隠れるため）
- **理由**
  - ユーザーは周期の行で直接オン・オフできるほうを好んだ（2026-10-31）
  - C は公開されていない API を呼ばない。Obsidian の描き方が変わって足せなくなっても、サブページのトグルと設定の検索は残り、使えなくなることはない
  - 見出しのトグルは、ADR-0033 で決めた形とステッカーの見た目をそのまま保てる
- **結果**: Obsidian の設定画面の DOM（`.setting-item.mod-navigable`、`.setting-item-control`）に頼る。Obsidian を更新したら、
  周期の行と見出しのトグルが出ているかを見る。行のトグルはラベルなので、行が開かないように click の伝わりを止める（`preventDefault` にするとトグルが切り替わらない）
