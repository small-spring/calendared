# ADR-0015 選択は開いているノートから求める

- **決定**: 選択中のノートを、書き換えられる値として持たない。Obsidian の「開いているノート」が変わったとき（`file-open`）だけ更新する、
  読み取り専用の状態にする（[ADR-0016](0016-vault-source.md) の窓口の `activeFile`）。ノートを開く処理など、ほかの場所は選択を書き換えない（ノートを開けば、選択はついてくる）
- **理由**: 元が 1 つになるので、ずれようがない。今いちばんずれやすいところ
- **決めたこと**（2026-10-30）: 「開いているノート」は Obsidian の `workspace.getActiveFile()` に従う。今のタブがファイルのビューならそのノート、
  カレンダーなどほかのビューにフォーカスがあるときは直前に使ったノート。窓口はこれを写しを持たずにそのまま聞く
