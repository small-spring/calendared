# ADR-0035 移行の案内は設定画面の消えない警告にし、移行が済むか「このままにする」で消して前の書式も忘れる

- **背景**: 書式やステッカーのプロパティを変えたあと、前の書式（プロパティ）のノートがカレンダーから見えなくなるので、移行へ案内すると決めていた
  （[ADR-0019](0019-one-format-per-period.md)、[ADR-0024](0024-migration-safety.md)）。知らせる形が決まっていなかった
- **検討した案**
  - A. 通知（数秒で消える）
  - B. 設定画面の中に出し、移行が済むまで出し続ける
  - C. 設定画面の中に自動では消えない警告を出し、移行が済むか、本人が「このままにする」を選んだら消す
- **決定**: C。「このままにする」は確認の画面を挟み、選んだら前の書式（プロパティ）も忘れて、設定画面にはもう出さない。
  通知は出さない
- **理由**
  - A は見落としやすい。あとで気づいたときに、どこから直せばいいかわからない
  - B は、前の書式のノートをわざと残したい人にも出し続けてしまい、前の書式もずっと覚えておくことになる
  - 前の書式は設定に残したくない（ADR-0019 で残さないと決めた理由と同じ）。C なら覚えておくのは警告が出ている間だけで済む
- **結果**: ADR-0019 の「前の書式は設定に残さない」を、「警告が出ている間だけ、周期ごとに 1 つ覚えておく」に変える。
  警告を消したあとに移行するときは、前の書式（プロパティ）を手で入れる。細かい形（もう一度書式を変えたときなど）は
  [plans/settings.md](../plans/settings.md) の「移行の案内」
