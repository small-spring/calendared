# ADR-0031 タイムラインを「パンくず」と「ミニカレンダー」の 2 つの機能に分け、それぞれ出す場所を選べるようにする

- **背景**: [ADR-0029](0029-timeline-purpose-and-navigation.md) で目的を決めたあとも、タイムラインの役目（位置を示すのか、小さなカレンダーなのか）で
  迷い続けた。要求と UI を同時に考えていたためなので、要求 → 部品の候補 → 組み合わせの案（モック）の順に分けて考え直した
  （[archive/navigation.md](../archive/navigation.md)）
- **要求**（archive/navigation.md の表）: いつも見えていてほしいのは、周期ノートでの位置と、近くのステッカー（流れがわかる）。
  1 回で行きたいのは、どのノートからでも今へ、周期ノートから前後とすぐ上へ。下へ移るのと遠くの日へは、カレンダーからでよい。
  PC とスマホで要求は同じで、PC ではサイドのカレンダーで満たせることが多い
- **検討した案**（モックで比べた）
  - A. パンくず＋前後の帯 / B. パンくずだけ / C. A に、パンくずから中の周期を出す ▾ を足す
  - 戻るボタンの置き方: 右上の角の丸いボタン / ノートのある側の名札 / 帯の下の「戻る」
  - 隠れ方: 見出しバーと一緒に隠れる / 本文と一緒に流れる / いつも出す
- **決定**
  - タイムラインを 2 つの機能に分ける。どちらも周期ノートの上（見出しバーのすぐ下）に出す
    - **パンくず**: `2026 › Q4 › 10月 › W44 › 30日`。上の周期を押すとそのノートを開く。一番右（開いているノート自身）を押すと、
      動かしたミニカレンダーがノートに戻る。使っていない周期のうち、週と四半期は出さない（なくても位置がわかる）。月と年は出し、
      押せないだけにする（色は変えない。薄くすると見栄えが悪く、もともと押せる感じが強くない）。ミニカレンダーがオフのときは、
      両端の ‹ › で前後のノートを開く。中央に揃える
    - **ミニカレンダー**: 前後の帯。ステッカー（数字の右上に傾けて重ねる）とノートの有無のドット付き。今日（今週・今月など）は、
      メインのカレンダーと同じ決まりで色を付ける。日は設定「日の並べ方」に従い、「週ごと」（既定。週の始まりはカレンダーの設定）か
      「ノートを真ん中に」（前後 3 日）の 7 日。週・月・四半期・年は、ノートを真ん中に前後 2 つずつ。‹ › は帯の幅ぶん動く
  - それぞれに「出す場所: いつも / スマホだけ / 出さない」と「周期ノートでないノートにも出す」を持たせる。周期ノートでないノートでは、
    一番細かい使っている周期の今を基準にする（パンくずは今日の位置。「今日」とは書かない）
  - ミニカレンダーだけのとき（パンくずがオフ）、開いているノートが帯から外れたら、帯の下の区切り線にまたがる形で「30日に戻る」を出す。
    ボタンがないときに空白を残さず、ほかの部品の場所を動かさない（続けて ‹ › を押せるように）。ノートのタイトルに被らないよう、本文を少し下げる
  - たたむボタン（⌃）、開閉の初期値の設定 2 つ、タブごとに開閉を覚えることはなくす。スマホでは、下へスクロールすると見出しバーと一緒に隠れ、
    少し上へ戻すと出る（今の作りのまま）。PC では見出しバーと同じくいつも出る
  - パンくずから中の周期を出す ▾ は作らない。過去の期間の中へ下りるのは、カレンダーから
  - ADR-0029 のうち、次は引き継ぐ: 「1 つ下の周期」「いつも日」「いつも今」を作らない。⌖ をなくす。下へは今へ飛んでから上る（Open now、[ADR-0030](0030-open-now.md)）
- **理由**
  - パンくずとミニカレンダーは満たす要求が違う（位置と上への移動 / 近くの様子と前後への移動）。分ければ、PC では減らしたい、
    スマホでは両方ほしい、といった好みに設定だけで応えられ、「タイムラインは何のためか」で迷わずに済む
  - 日だけ週の区切りに揃えるのは、メインのカレンダーと曜日の並びが揃い、週単位で暮らす人には今週がひとまとまりで見えるため。
    週を意識しない人のために「ノートを真ん中に」を残す。月を四半期で区切るような並べ方は、週ほど暮らしの区切りにならない
  - 出す場所を端末ごとの値（`app.saveLocalStorage`）で持つ形は、新しい端末で設定し直すことになり、どこで何を設定したかわかりにくい
  - 本文と一緒に流れる形だと、書きながら昨日や明日を見るのに一番上まで戻る必要がある。見出しバーと一緒なら、少し上へ戻すだけで出る
  - 戻るボタンを帯の端に足すと、出たときに ‹ › の場所がずれ、続けて押せなかった（モックで確かめた）
- **結果**: 今の設定の「Unique timelines」「Periodic notes timeline view mode」「Non-periodic notes timeline view mode」は消え、
  「Timeline」と「Show timeline everywhere」は機能ごとの設定に分かれる。週の端の日のノートで「週ごと」にしていると、片側の隣の日が帯に出ない
  （› で次の週に送ってから押す）。設定画面での並べ方は [spec/overview.md](../spec/overview.md) の「4. パンくずとミニカレンダー」
- **追記（2026-10-31）**: 「出さない」は出す場所の選択肢から外し、見出しのトグルでオン・オフする形にした（[ADR-0033](0033-heading-toggles.md)）
